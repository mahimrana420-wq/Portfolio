# MD. Mahim Rana - Portfolio

A responsive dark/purple portfolio website inspired by the provided demo.

## Files
- `index.html` - main website
- `style.css` - design and responsive layout
- `script.js` - menu, theme toggle, reveal animations and active navigation
- `images/profile.jpg` - profile image extracted from the CV
- `MD_Mahim_Rana_CV.pdf` - CV

## Run locally
Open `index.html` in VS Code with Live Server, or simply open it in a browser.

## GitHub Pages
1. Create a GitHub repository, for example `portfolio`.
2. Upload all files and folders.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose `main` and `/ (root)`.
6. Save.
